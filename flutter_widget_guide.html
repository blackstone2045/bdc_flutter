1. Container Widget

The most versatile widget for styling, sizing, and positioning

Beginner

📖 What is Container?

A Container is a box that holds a single child widget. It's used for decoration, positioning, and sizing. Think of it as a div in HTML.

🎨 Design Output

┌─────────────────────────────────────┐
│  ╔═══════════════════════════════╗   │
│  ║   Styled Container            ║   │
│  ║   (Gradient + Shadow)         ║   │
│  ╚═══════════════════════════════╝   │
│                                     │
│           ⭕ Circle                 │
│        (with teal border)           │
│                                     │
│  ┌ - - - - - - - - - - - - - - ┐  │
│  │  With Dashed Border          │  │
│  └ - - - - - - - - - - - - - - ┘  │
└─────────────────────────────────────┘

💻 Code Example

// Styled Container with Gradient
Container(
  width: 200,
  height: 100,
  decoration: BoxDecoration(
    gradient: LinearGradient(
      colors: [Colors.purple, Colors.blue],
    ),
    borderRadius: BorderRadius.circular(15),
    boxShadow: [
      BoxShadow(
        color: Colors.black26,
        blurRadius: 10,
        offset: Offset(0, 5),
      ),
    ],
  ),
  child: Center(
    child: Text(
      'Styled Container',
      style: TextStyle(
        color: Colors.white,
        fontWeight: FontWeight.bold,
      ),
    ),
  ),
)

// Circle Container
Container(
  width: 150,
  height: 150,
  decoration: BoxDecoration(
    color: Colors.redAccent,
    shape: BoxShape.circle,
    border: Border.all(color: Colors.teal, width: 5),
  ),
  child: Center(child: Text('Circle')),
)
PropertyPurpose
width/heightSet dimensions
colorBackground color
paddingSpace INSIDE container
marginSpace OUTSIDE container
decorationAdvanced styling (BoxDecoration)
alignmentPosition child inside
transformRotate, scale, translate

2. Row & Column Widgets

Arrange widgets horizontally (Row) or vertically (Column)

Beginner

📖 What are Row & Column?

Row arranges children HORIZONTALLY (left to right).
Column arranges children VERTICALLY (top to bottom).

🎨 Design Output

ROW Example:
┌────────────────────────────────────────┐
│ [Red Box]    [Teal Box]    [Green Box] │
│  60x60        60x60         60x60      │
│  (spaceBetween - evenly distributed)   │
└────────────────────────────────────────┘

COLUMN Example:
┌────────────────────────────────────────┐
│ ┌────────────────────────────────────┐ │
│ │           Blue Bar                 │ │
│ └────────────────────────────────────┘ │
│ ┌────────────────────────────────────┐ │
│ │          Purple Bar                │ │
│ └────────────────────────────────────┘ │
│ ┌────────────────────────────────────┐ │
│ │           Pink Bar                 │ │
│ └────────────────────────────────────┘ │
│    (spaceEvenly - equal spacing)       │
└────────────────────────────────────────┘

💻 Code Example

// ROW - Horizontal arrangement
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Container(
      width: 60, height: 60,
      color: Colors.redAccent,
      child: Center(child: Text('1')),
    ),
    Container(
      width: 60, height: 60,
      color: Colors.teal,
      child: Center(child: Text('2')),
    ),
    Container(
      width: 60, height: 60,
      color: Colors.greenAccent,
      child: Center(child: Text('3')),
    ),
  ],
)

// COLUMN - Vertical arrangement
Column(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [
    Container(height: 50, color: Colors.blue),
    Container(height: 50, color: Colors.purple),
    Container(height: 50, color: Colors.pink),
  ],
)
PropertyValues
mainAxisAlignmentstart, center, end, spaceBetween, spaceAround, spaceEvenly
crossAxisAlignmentstart, center, end, stretch, baseline
mainAxisSizemin, max
💡 Pro Tip: Use MainAxisAlignment.spaceBetween for even spacing, and CrossAxisAlignment.stretch to make children fill the cross axis.

Text(
  'Hello, Flutter!',
  style: TextStyle(
    fontSize: 24,
    fontWeight: FontWeight.bold,
    color: Colors.blue,

    decoration: TextDecoration.underline,

  maxLines: 2,
  overflow: TextOverflow.ellipsis,
  textAlign: TextAlign.center,
  style: TextStyle(height: 1.5),

colorText color
fontStylenormal or italic

wordSpacingSpace between words
decorationunderline, lineThrough

// Elevated Button
ElevatedButton(
  onPressed: () {
    print('Pressed!');
  },
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.blue,
    padding: EdgeInsets.symmetric(horizontal: 40, vertical: 15),
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(25),
    ),
    elevation: 5,
  ),
  child: Text('Elevated Button'),
)

// Text Button
TextButton(
  onPressed: () {},
  child: Text('Text Button'),

  onPressed: () {},

  child: Text('Outlined'),
)

// Icon Button
IconButton(
  icon: Icon(Icons.favorite),
  color: Colors.red,
  iconSize: 30,
  onPressed: () {},
)

// Gradient Button
InkWell(
  onTap: () {},
  child: Container(
    padding: EdgeInsets.all(15),
    decoration: BoxDecoration(
      gradient: LinearGradient(
        colors: [Colors.purple, Colors.blue],
      ),
      borderRadius: BorderRadius.circular(25),

    child: Center(
      child: Text('Gradient Button',

💻 Code Example

// Network Image with loading
Image.network(
  'https://picsum.photos/200/300',
  width: 200,
  height: 150,
  fit: BoxFit.cover,
  loadingBuilder: (context, child, progress) {
    if (progress == null) return child;
    return CircularProgressIndicator();
  },
  errorBuilder: (context, error, stack) {
    return Icon(Icons.error, size: 50);
  },
)

// Asset Image (declare in pubspec.yaml first!)
Image.asset(
  'assets/images/logo.png',
  width: 150,
  height: 150,
  fit: BoxFit.contain,
)

// Circular Image
ClipOval(
  child: Image.network(
    'https://i.pravatar.cc/150',
    width: 100,
    height: 100,
    fit: BoxFit.cover,
  ),
)

// Rounded corners
ClipRRect(
  borderRadius: BorderRadius.circular(20),
  child: Image.network(
    'https://picsum.photos/300/200',
    fit: BoxFit.cover,
  ),
)
💡 Don't forget: For asset images, add to pubspec.yaml:
flutter: assets: - assets/images/

TextField(

    labelText: 'Email',
    hintText: 'Enter your email',

    border: OutlineInputBorder(

// Simple ListView
ListView(
  padding: EdgeInsets.all(16),
  children: [
    ListTile(
      leading: CircleAvatar(child: Text('1')),
      title: Text('Item One'),
      subtitle: Text('Subtitle'),
      trailing: Icon(Icons.arrow_forward),
      onTap: () {},
    ),
    Divider(),
    ListTile(
      leading: CircleAvatar(child: Text('2')),
      title: Text('Item Two'),
    ),
  ],
)

// Dynamic ListView (BEST for long lists!)
ListView.builder(
  itemCount: 100,
  itemBuilder: (context, index) {
    return ListTile(
      leading: CircleAvatar(
        backgroundColor: Colors.primaries[index % 18],
        child: Text('${index + 1}'),
      ),
      title: Text('Item ${index + 1}'),
      subtitle: Text('Subtitle $index'),
      trailing: Icon(Icons.chevron_right),
      onTap: () {
        print('Tapped $index');
      },
    );
  },
)

// Horizontal ListView
ListView.builder(
  scrollDirection: Axis.horizontal,
  itemCount: 10,
  itemBuilder: (context, index) {
    return Container(
      width: 150,
      margin: EdgeInsets.all(8),
      color: Colors.primaries[index % 18],
      child: Center(child: Text('Card $index')),
    );
  },
)
💡 Performance Tip: Always use ListView.builder for lists with more than 20 items!

11. Stack Widget

Overlay widgets on top of each other

Intermediate

📖 What is Stack?

Allows widgets to overlap. First child = bottom layer, last child = top layer.

🎨 Design Output

┌────────────────────────────────────────┐
│  ┌─────────────────────────────┐       │
│  │  🖼️ Image (bottom layer)    │       │
│  │                             │       │
│  │  [NEW]              (badge) │       │
│  │                    Overlay  │       │
│  │  Overlay Text      Text     │       │
│  └─────────────────────────────┘       │
│                                        │
│         ⭕ Avatar                      │
│            🔴 (online dot - top right) │
└────────────────────────────────────────┘

💻 Code Example

Stack(
  children: [
    // Bottom layer - Image
    Container(
      width: 200,
      height: 150,
      decoration: BoxDecoration(
        borderRadius: BorderRadius.circular(10),
        image: DecorationImage(
          image: NetworkImage('https://picsum.photos/200/150'),
          fit: BoxFit.cover,
        ),
      ),
    ),
    // Top layer - Text
    Positioned(
      bottom: 10,
      left: 10,
      child: Text(
        'Overlay Text',
        style: TextStyle(
          color: Colors.white,
          fontWeight: FontWeight.bold,
          shadows: [Shadow(blurRadius: 4)],

class DropdownExample extends StatefulWidget {
  @override
  _DropdownExampleState createState() => _DropdownExampleState();
}

class _DropdownExampleState extends State {
  String? selectedCountry;
  List countries = [
    'Bangladesh',
    'India',
    'Pakistan',
    'Sri Lanka',
    'Nepal',
  ];

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        DropdownButton(
          value: selectedCountry,
          hint: Text('Select Country'),
          isExpanded: true,
          items: countries.map((String country) {
            return DropdownMenuItem(
              value: country,
              child: Text(country),
            );
          }).toList(),
          onChanged: (String? value) {
            setState(() {
              selectedCountry = value;
            });
          },
        ),

        // Styled dropdown
        Container(
          padding: EdgeInsets.symmetric(horizontal: 16),
          decoration: BoxDecoration(
            border: Border.all(color: Colors.grey),
            borderRadius: BorderRadius.circular(8),
          ),
          child: DropdownButtonHideUnderline(
            child: DropdownButton(
              value: selectedCountry,
              hint: Text('Choose...'),
              icon: Icon(Icons.arrow_drop_down),
              isExpanded: true,
              items: countries.map((String country) {
                return DropdownMenuItem(
                  value: country,
                  child: Row(
                    children: [
                      Icon(Icons.flag),
                      SizedBox(width: 10),
                      Text(country),
                    ],
                  ),
                );
              }).toList(),
              onChanged: (value) {
                setState(() {
                  selectedCountry = value;
                });
              },
            ),
          ),
        ),
      ],
    );
  }
}
